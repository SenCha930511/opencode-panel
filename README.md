# opencode-panel

Sidebar chat panel (VSCode extension) that drives your locally installed
[opencode](https://opencode.ai) through its headless server — multi-session
chat, streaming responses, permission approvals, attachments, diffs and more.

> Status: early development scaffold. See `.omo/plans/opencode-vscode-sidebar.md`
> for the work plan.

## Development

```sh
npm install
```

Building, testing and packaging instructions land with later scaffold todos.
